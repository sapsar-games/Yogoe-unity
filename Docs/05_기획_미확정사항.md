## A. v1.2 — 정해야 할 것 (2026-10-06)

비교 근거: v1.2 기획서 · 시연 역기획 [`09`](./09_v1.2_시연_역기획.md) · 인터랙션 [`08`](./08_유저인터랙션_v1.2.md).

### A1. 공덕 기물 값
v1.3 기획서(2026-10-06)가 시연값을 확정해 나머지 차이는 풀림 — 음식 +10 · 공양물 +15/+1 · 요구 −10 · 주문 요괴 +30/+10·+5 · 혼령 조각 1/2 (시트 `game_settings`).

### A2. 데이터
- `recipes` 탭 빈 id 16줄 — 채워야 레시피 반영 가능.

### A3. 기획서에 없는 동작

- 기존 황금쌀·황금꿀 보유분 처리.

### A4. MVP 이후로 미뤄도 되는 것
요괴 특성 · 기억해내기 공덕 값 · 떡절구 개편.

## B. 아직 안 정해진 것

### B1. 드래그 "1회차인데 엔딩기물, 떡절구"
6-3 "조건에 맞지 않는 기물(1회차인데 엔딩기물, 떡절구, 이미 점유된 기물)". '1회차'의 뜻 — 1회차엔 떡절구에 **아무도(옥토끼 포함)** 못 앉는지, 주인 아닌 요괴만인지.
- **지금 구현:** 주인(옥토끼)만 앉을 수 있음. 다른 요괴 → (x).

### B2. "엔딩기물 2개"의 정체
8장 "엔딩기물 2개는 전부 떡절구의 레벨에 따른다" — 정의된 엔딩기물은 떡절구 하나. 다른 요괴 엔딩기물이 나올 예정인지, 다른 뜻인지.  
(MVP는 떡절구만 집중)

### B3. 오프라인 중 추가 보관(오버플로우) 판정
방치 수익 `min(보관량, …)`의 "보관량"이 오버플로우 포함인지.
- **지금 구현:** 오프라인도 온라인과 똑같이 판정.

## C. v1.3 — 기획은 정해졌는데 코드가 아직 안 따라간 것 (2026-10-08 대조)

`[기획문서] 한폭요괴 1.0.docx`("기물·공양간·나루터 통합 기획 v1.3")를 코드와 전체 대조한 결과.
**B처럼 결정이 필요한 게 아니라, 이미 결정된 걸 아직 안 만든 것** — 구현되면 여기서 지운다.

### C1. 황금재료 재설계
기획서: 황금쌀·황금꿀 폐지 → 산나물·약재·고추·해산물·새고기·새알 **6종 각각 1%**로 황금 버전이 나옴(절벽의 약초골·파도치는 섬 전용), 섞인 요리는 황금 요리(10분간 3배속).
- **지금 코드:** `Assets/Scripts/Data/Enums.cs`의 `SpecialItemId`는 여전히 `GoldenRice`/`GoldenHoney` 둘뿐. `PropCatalog.cs:55` 부근 주석이 "황금 확률%(황금 재료 개편 전까지 안 씀)"이라고 스스로 적어둠 — 개편 들어갈 자리는 파놨지만 미연결.
- **데이터는 이미 준비됨:** `Assets/Resources/ingredients.json`에 `GoldenChili`·`GoldenNamul`·`GoldenHerb`·`GoldenBird`·`GoldenFish`·`GoldenEgg` 6종이 이미 정의돼 있음 — 코드(Enums·`IngredientDraw`·`PropCatalog`)만 이 데이터를 쓰도록 바꾸면 됨.
- A3의 "기존 황금쌀·황금꿀 보유분 처리"와 연결된 작업.

### C2. 옥토끼 NPC화
기획서: 옥토끼는 슬롯에서 빠지는 NPC. 친밀도 100 고정, 기력 바만 있음, 떡절구만 찧음, 윷놀이에서 빠짐.
- **지금 코드:** 여전히 일반 슬롯 캐릭터. `YutMiniGame.Pieces.cs:465` 근처에서 윷놀이 말로도 그대로 등장.
- A3 "옥토끼 NPC화 뒤 슬롯 구성"과 `08` 문서 "기획 확인 필요 모음" 6번("옥토끼 NPC의 상세 화면·공양 가능 여부")도 이 작업에 같이 묶임.

### C3. 요리책 새 레시피 → 엽전 보상
기획서: 요리책에서 처음 발견한 레시피 칸마다 엽전 1개(미발견 76개 기준 최대 76개). `08` 문서 §6에도 이미 "엽전 표시가 붙은 칸(새 레시피) → 엽전 1개 받기"로 기록돼 있음.
- **지금 코드:** `CookingCodex.cs`에 엽전 지급 로직 없음. 지금 엽전 수급처는 출석 윷점·윷놀이 보물상자뿐(A3 "엽전 수급처" 항목과 직결).

### C4. 화면 감상(30초 UI 자동 숨김)
기획서: 30초간 입력 없으면 HUD가 화면 밖으로 밀려나며 숨고, 탭 한 번으로 복귀(그 탭 자체는 다른 동작으로 안 이어짐). `08` 문서 §7에 이미 기록돼 있음.
- **지금 코드:** 관련 로직 전혀 없음(검색 결과 없음).

### 미조사 (확인 안 함 — "문제없음"이 아니라 그냥 안 본 것)
먹이기 창 세부 UX(꾹 눌러 연속 먹이기 · 음식/공양물 탭 기억) · 레벨업 딱지 우선순위 · 공양간 잇기(대각선·천리안 부적) 세부 로직 · 엽전 패키지 결제 동작.
