## 3. 사냥터 · 채집터 보내기 팝업 (신규)

| 입력 | 결과 |
|---|---|
| 팝업 열기 | 위: 목적지 3곳 (나오는 재료 · 입장 친밀도 0/25/50) · 아래: 보낼 수 있는 요괴 |
| 목적지 탭 | 선택 |
| 요괴 탭 | 선택. 다른 데서 일하는 중 · 기력 0 · 기절이면 **흐리게** (선택 불가) |
| [보내기] — 친밀도 충분 | 요괴가 그 목적지로 가서 일 시작 (15분/1개, 10분당 기력 1) |
| [보내기] — 친밀도 부족 | 요괴가 "거기는 가기 싫어" + **필요 친밀도 표시**, 보내지 않음 |
| [불러들이기] (현황 창) | 일을 멈추고 돌아옴 ❓ 돌아온 뒤 상태(놀기?)와 쌓인 재료 처리 |

자동: 보관함이 차면 → 빈 옹달샘·북제단·남제단 중 무작위로 옮겨 감 → 없으면 놀기. 기력이 남은 채 놀면 기절하지 않음.

## 기획 확인 필요 모음 (❓)

1. 일하는 중인 요괴·기물을 탭하면 **수거 / 현황 + 불러들이기 / 혼잣말** 중 무엇인지 (모두 같은 탭)
2. 드래그 착석을 남길지, 옹달샘·제단에는 어떻게 보내는지
3. 제단 공덕 수거 방식과 공덕 버드나무 유지 여부
4. [불러들이기] 뒤 요괴 상태
5. [부엌으로] → 요리 뒤 나루터로 돌아오는지
6. 옥토끼 NPC의 상세 화면·공양 가능 여부
7. 기물 시작 상태 (자물쇠·구매)
