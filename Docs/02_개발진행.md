## 남은 작업

**구현 안 됨**
1. 사운드 — 목탁·엽전·풍경·나무·가야금 (음원 필요)
2. 서버 시각 — Firebase 연동 (`TrustedTime.SetServerOffset` 자리만 있음)
3. 광고 SDK — 지금은 전부 스텁(바로 성공)

**기획 결정 필요**
- 캐릭터 상세 설명 문구 (시트 `characters` 옛 문구 → PDF [제안] 문구로 교체할지)
- 구미호 선호 '막걸리'가 음식 종류(재료 2)라 선호여도 친밀도 0 — 레시피·선호·규칙 중 무엇을 바꿀지
- `05`: B1 '1회차 엔딩기물', B2 엔딩기물 2개, B3 오프라인 넘침 판정, 상점 진열 품목

**아트 교체 (🎨 임시)** — 표정 힌트, 드래그 표시, 황금 반짝임, 버드나무, 윷점 화면, 요리·재료 아이콘 등

**플레이 검증** — Unity에서 직접 확인 못 한 새 팝업(업그레이드·확인·요리책)·탭 우선순위·공양간 흐름
