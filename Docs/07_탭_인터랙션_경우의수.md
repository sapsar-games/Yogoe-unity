## 2. 드래그 규칙 상세

1. **들어올리기:** 요괴를 길게 누르면 들어올림 상태가 되며, 착석 가능한 빈 기물에 유도 표시(금색 강조)가 뜸.
2. **착석 (일 시작):** 착석 가능한 빈 기물 위에 놓으면 즉시 앉아 `머물기(일)` 시작.
3. **착석 불가 드롭:**
   - 이미 다른 요괴가 앉아 있는 기물
   - 조건 불일치 기물 (예: 옥토끼 외의 요괴를 떡절구에 드롭)
   - 위 경우 기물 **옆 바닥에 내려놓고 3초간 `(X)` 딱지**가 뜬 뒤 `놀기` 상태로 전환.
4. **바닥 드롭:** 기물이 아닌 길바닥에 놓으면 **3초간 `(?)` 딱지**가 뜬 뒤 `놀기` 상태로 전환.
5. **기절 상태:** 기절한 요괴는 **드래그 불가**. (상세 화면에서 물로만 기력 0→1 회복 가능)

## 3. 머리 위 표시 우선순위

```
윷놀이 귀환 획득품(수거 대기) > 음식 요구(1분 제한) > 혼잣말 말풍선
```

* **음식 요구 말풍선:** 
  - 기력 $\le \text{최대} - 8$일 때 3~5분 간격 추첨.
  - 탭 시 즉시 캐릭터 상세 화면으로 진입하며, 하단 아이템 목록에서 요구 대상 음식이 강조됨.
  - 1분 동안 미해결 시 소멸.
* **윷놀이 귀환 획득품:**
  - 윷놀이 종료 후 요괴들이 자신이 얻은 보상(부적, 특수칸 자원 등)을 들고 있음.
  - 요괴 또는 아이콘 탭 시 개별 수거되어 인벤토리로 지급.

## 4. 자원 수거 체계 요약

| 대상 | 수거 방식 | 비고 |
|---|---|---|
| **자원 기물 3종** (옹달샘·활터·약초밭 — 갯바위는 v1.2로 삭제) | 기물 본체 탭 $\rightarrow$ **개별 수거** | 기물에 쌓인 물, 사냥/채집 재료 인벤토리로 획득. 광고 없음. |
| **공덕 (떡절구 생산)** | **공덕 버드나무** 탭 $\rightarrow$ **일괄 수거** | 떡절구에서 날아간 꽃잎이 버드나무에 누적. 탭 시 HUD로 카운트업. **30분 만창 시 핑크색 변환 및 '광고 보고 2배 / 그냥 받기' 팝업**. |
| **화덕** | 탭 시 요리 화면 | 생산 자원 없음 (수거 대상 아님). |
