## 2. 기획서에 없던 것 — 시연이 정한 동작

### 2-1. 맵 입력 (→ `08`의 ❓ 1·2·4 답)

| 대상 | 입력 | 시연 동작 |
|---|---|---|
| 기물 (보관함에 뭔가 있음) | 탭 | **바로 수거**. 2초 안에 다시 탭하면 기물 창이 열림 |
| 기물 (보관함 빈) | 탭 | 기물 창 (보내기 / 일하는 중) |
| 기물 왼쪽 위 ▲ 딱지 | 탭 | 기물 창 — 공덕이 레벨업 비용 이상일 때만 딱지가 보임 |
| 일하는 중인 요괴 | 탭 | 일 대사 + 토스트 "○○ · 어디에서 사냥 중 · 보관함 n/15 · 기력 n". **불러들이기는 기물 창에서만** |
| 가는 중인 요괴 | 탭 | "○○로 가는 중이야." |
| 노는 요괴 | 탭 | 혼잣말 + 깡충 + **먹이기 창** |
| 배고픈 요괴 · 기력 0 요괴 | 탭 | 배고픔/지침 대사 + 먹이기 창 |
| 요괴 머리 위 그릇 | 탭 | 먹이기 창 |
| 요괴 → 옹달샘·북제단·남제단 | 드래그 | **바로 일 시작** (점유 · 가득 · 기력 0이면 토스트로 거절) |
| 요괴 → 사냥터·채집터 | 드래그 | 기물 창이 열리고 그 요괴가 미리 골라짐 (목적지를 골라야 하므로) |
| 일하는 중인 요괴 | 드래그 | 안 됨 |
| 떡절구 | 탭 | 공덕 300 이상이면 수거 + "공덕 ○○이에요! 열심히 찧었어요." / 아니면 옥토끼 안내 대사 5종 중 하나 |
| 화덕 / 나루터 | 탭 | 화덕 탭 / 나루터 탭으로 이동 |
| 일괄 레벨업 버튼 (마당 전용) | 꾹 누르기 | 비용이 가장 싼 기물부터 한 단계씩 연속 (처음 4번 0.32초, 그 뒤 0.18초 간격). 짧게 누르면 한 단계. 끝나면 "레벨업 n번 · 공덕 ○ 남음" |

### 2-2. 기물 창

**보내기 (비어 있을 때)**
- 사냥터·채집터: 위에 목적지 카드 3장(그림 · "황금 1%" 표 · 이름 · "♥ 친밀도 25 이상" 또는 "누구나 · 희귀도 하" · 재료 아이콘). 지난번에 고른 목적지가 기본 선택.
- 옹달샘·제단: 목적지 없이 "○○에서 일할 요괴" + "요괴를 이 기물로 끌어다 놓아도 바로 시작해요".
- 요괴 카드 3장(삼족오·구미호·고라니): 표정 · 친밀도 · 기력 바 · 상태 문구.
  - 상태 문구: "갈 수 있어요" / "○○에서 일하는 중" / "지쳐서 쉬는 중 · 먹여 주세요" / "친밀도 20/50 · 누르면 물어봐요"
  - **친밀도가 모자란 요괴를 누르면** 카드가 흔들리고 요괴가 "거기는 가기 싫어." + "○○는 친밀도 50부터 가요 · 지금 20" (2.6초)
- 요약 줄: "기력 22이면 약 3시간 40분 일하고 쉬어요 (14개쯤)" 또는 "약 3시간 45분이면 보관함이 차고, 남은 기력 ○로 빈 옹달샘·제단에 옮겨 가요"
- 버튼: [○○ 보내기] · [레벨업 Lv1 → 2 / 공덕 500]

**일하는 중**
- 요괴 얼굴 · "어디에서 사냥하는 중 (보관함이 차서 옮겨 옴)" · 보관함 칸(황금은 금칸) n/15 · 기력 바
- "다음 것까지 약 n분 · 15분에 1개 (황금 요리면 3개 · n분 남음)"
- 가는 중: "도착하면 일을 시작해요. **가는 동안엔 기력이 닳지 않아요.**"
- 버튼: [불러들이기] [받기 n개] [레벨업]
- **불러들이기** → 일을 멈추고 "다녀왔어." · 놀기로. 보관함 재료는 기물에 그대로 남음 (→ `08` ❓4 답)

**레벨업**
- 사냥터·채집터·옹달샘: "수거할 때마다 (Lv%10)×10% 확률로 한 칸 더". 그 한 칸은 **수거할 때 굴림**.
- 제단: "보관량 ○ (×1.1)".
- Lv 10·20·30… → 팝업 "레벨업! · ○○ Lv10 · 보관함의 총량이 +1 되었어요 · 보관함 15 → 16"

### 2-3. 먹이기 창 (신규 화면 — 요괴 상세 화면 대신)
- 제목 "○○ 먹이기" · "친밀도 n · 음식 +10 · 공양물 +15" · 기력 바 · 가득 찰 때까지 몇 그릇인지.
- [아무거나 먹이기]: 많은 것부터. **황금 요리와 혼령이 청한 요리는 뺌**.
- [음식만] / [공양물 포함] 토글 (기억함). 공양물 포함이면 그 요괴의 **선호 공양물이 금빛으로 맨 앞**.
- 목록 정렬: 선호 → 황금 → 개수 많은 순 → 이름순.
- 누르면 한 그릇, **0.3초 넘게 꾹 누르면 기력이 가득 찰 때까지 0.3초마다 계속** (손가락이 8px 넘게 움직이면 스크롤로 보고 멈춤).
- 기력이 가득이면 음식은 "배가 불러요"로 거절. 공양물은 가득이어도 바칠 수 있음(친밀도만).
- 창고가 비면 "화덕에서 요리판을 돌려 지어 오세요" + [화덕으로].

### 2-4. 요리판 세부
- **잇기 두 방식:** 끌어서 잇기 또는 하나씩 눌러 잇기. 눌러 잇는 중 2개짜리 레시피가 완성되면 "○○ — 마지막 재료를 한 번 더 누르면 익어요 · 빛나는 칸을 더 이으면 공양물". 다른 곳을 누르면 취소. 직전 칸으로 되돌리면 한 칸 취소.
- **판 깔기:** 창고에서 무작위 20개. 그 20개로 지을 조합이 없으면 창고 전체에서 지을 수 있는 조합을 먼저 넣음. **보장 조합 하나를 가로나 세로로 이웃하게** 놓고 나머지는 무작위 칸.
- 지을 수 있는 조합이 하나도 없으면 시작 불가: "지금 가진 재료로는 지을 수 있는 조합이 없어요".
- 시작 화면: 고른 부적 설명 · **나루터 혼령이 청한 요리 목록(금색)** · 창고 요리 수 · [요리 시작 · 15초].
- 남은 5초부터 초마다 '톡'.
- 시간 끝 연장 창 → [광고 보고 15초 더] / [이번 판 종료]. 연장 후 "15초가 더해졌어요 · 멈췄던 요리도 이어서 익어요".
- 결과창 제목: "시간 끝" / "막다른 판 — 끝". 줄: "김 오를 때 꺼낸 요리 n번 · 몰빵 ×2 · ○○에게 ○○을 완벽하게 대접했어요 (친밀도 +10 · 기력 +30)". 새 레시피마다 "엽전 1".
- 화덕 탭에 판이 돌아가는 중이면 '…' 점.

### 2-5. 나루터 세부 (→ `08` ❓5 답)
- 혼령 4종의 말투:

| 혼령 | 주문 | 대접 | 떠날 때 |
|---|---|---|---|
| 여자 | ‘○○’ 주세요. | 고마워요. | …배가 떠나네요. |
| 남자 | ‘○○’ 주시오. | 고맙소. | …배가 떠나는구려. |
| 노인 | ‘○○’ 한 그릇 주게. | 고맙네. | …배가 떠나는군. |
| 어린이 | ‘○○’ 줘! | 고마워! | 배 간다… |

- 주문 고르기: 줄에 이미 있는 요리는 **되도록 겹치지 않게**. 지을 수 있는 요리가 하나도 없으면 혼령이 오지 않음("지을 수 있는 요리가 없어 혼령이 오지 않아요").
- 아래 줄 표시: "줄 n/5 · 다음 혼령 n분 · n명에게 바로 내줄 수 있어요".
- 남은 시간 30분 아래면 빨갛게. 창고에 있으면 혼령이 빛남.
- 혼령 창: 주문 대사 · 청하는 요리(음식/공양물 · "아직 지어 본 적 없음") · 창고 n그릇 · "내주면 기억 조각 n개".
- [부엌으로] → 화덕 탭 + "○○을 지어서 나루터로 돌아오세요" (**자동으로 돌아오지는 않음**).
- 다른 탭에 있을 때 혼령이 오면 토스트 "나루터에 혼령이 내렸어요 · ○○을 청해요". 나루터 탭에 줄 인원 점.

### 2-6. 요리책 · 창고
- 칸: 지은 요리 = 아이콘 · 이름 · 그릇 수, 안 지은 요리 = 이름 + "?". 엽전 받을 칸에 표시, 탭에 받을 개수 점.
- 엽전 칸을 누르면 엽전 +1 연출 뒤 상세 팝업 "새 레시피를 열었어요 · 엽전 +1".
- 상세: 아이콘 · **설명(`d`)** · **만드는 법(`h`, 실제 조리법 글)**. **재료 조합은 어디에도 적지 않음** — 요리판에서 찾음.
- 상세의 [요괴에게 먹이기/바치기] → **누구에게?** 창(요괴 3장, 선호면 강조) → 바로 먹임.
- 재료 칸도 요리책 맨 위에 개수와 함께(황금 수 포함).

### 2-7. 화면 감상
- 기획서대로 30초 무입력이면 UI가 숨음. 시연은 **마당 탭에서만**, 창이 열려 있으면 안 숨음.

### 2-9. 옥토끼 (→ `08` ❓6 답)
- 보내기 목록에 없음("떡절구만 찧어요"). 친밀도 100 · 기력 75 고정. 먹이기·주문 요괴 대상 아님.

## 3. `08` 확인 필요 목록과 시연의 답

| `08` ❓ | 시연의 답 |
|---|---|
| 1. 일하는 중 요괴·기물 탭 | 기물 탭 = 수거(2초 안에 다시 = 창), 요괴 탭 = 일 대사 + 현황 토스트 |
| 2. 드래그 착석 · 옹달샘·제단 보내기 | 드래그 유지. 옹달샘·제단은 드래그로 바로, 사냥터·채집터는 창이 열림 |
| 3. 제단 공덕 수거 | 제단을 눌러 받음 (버드나무 없음 — 시연엔 버드나무가 없다) |
| 4. 불러들이기 뒤 | 놀기, 보관함 재료는 기물에 남음 |
